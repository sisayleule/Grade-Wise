# Grade-Wise
A school academic management platform that helps schools manage students, grades, academic records, and generate reports.
#### Preview

 - [Demo](https://themewagon.github.io/horizon-next/)

#### Download
 - [Download from ThemeWagon](https://themewagon.com/themes/horizon-next/)

## Getting Started

1. Clone Repository
```
git clone https://github.com/themewagon/horizon-next.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
